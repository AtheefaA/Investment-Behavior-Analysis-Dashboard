# 📊 Cognifyz Task 7 – Power BI Dashboard

## 📌 Project Overview

This repository contains my **Task 7** submission for the **Cognifyz Technologies Internship**. The project demonstrates data analysis and visualization using **Microsoft Power BI** to transform raw data into meaningful business insights through an interactive dashboard.

---

## 🎯 Objectives

* Import and analyze the provided dataset.
* Clean and transform data for better analysis.
* Build interactive visualizations and reports.
* Identify trends and patterns in the data.
* Present insights in a clear and user-friendly dashboard.
